README - Petunjuk singkat
==========================
File ini adalah template situs responsif untuk permainan ringan "Nomor Pembohong Publik".
Catatan penting:
- Template ini TIDAK menggunakan nomor pribadi mana pun. Gantilah nomor hanya jika kamu punya izin.
- Jangan gunakan situs ini untuk menuduh, melecehkan, atau menyebarkan data pribadi orang lain.
- Kamu bebas mengubah desain, menambahkan fitur, dan mengunggah ke GitHub.

Cara pakai:
1. Ekstrak zip ini.
2. Buka index.html di browser untuk melihat tampilan.
3. Edit files jika perlu, kemudian buat repositori GitHub dan unggah.
